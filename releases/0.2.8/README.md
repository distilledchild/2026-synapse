# Synapse 0.2.8 — 메시지 앱과 같은 상대 이름

Apple 메시지가 선택한 참가자 이름을 읽어 대화 목록·제목·이니셜·검색에 사용합니다. 메시지 DB에 이름이 비어 있고 Contacts 검색이 이름을 찾지 못하던 대화도 표시합니다. 명시된 업체·그룹 이름과 전송 대상은 유지합니다.

- [설치 DMG](Synapse-0.2.8-arm64.dmg)
- [설치 안내](Synapse-local-test-guide.md)
- [소스 ZIP](Synapse-0.2.8-source.zip)
- [SHA-256](Synapse-0.2.8-SHA256.txt)

자동 검사 203개 통과. 설치된 실제 Synapse 0.2.8에서 사용자 스크린샷의 두 대화 이름이 Apple 메시지와 일치함을 확인했습니다. 테스트 중 메시지나 사진을 실제 발신하지 않았습니다.

기존 한 줄 입력창·Enter 전송·Shift+Enter 줄바꿈·첨부 이미지·링크 썸네일·사진 전송 기능을 유지합니다. 기존 앱에서 새 설치를 할 경우 앱을 종료하고 교체한 뒤 연결하세요. 개인 개발용 서명이라 앱 교체 후 기존 읽기 권한을 다시 적용해야 할 수 있습니다.
