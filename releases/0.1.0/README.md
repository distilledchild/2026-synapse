# Synapse 0.1.0 산출물

- Synapse-0.1.0-arm64.dmg: Apple Silicon 로컬 테스트 설치 파일.
- Synapse-0.1.0-source.zip: 해당 빌드를 생성한 소스 스냅샷.
- Synapse-0.1.0-native.patch: 최초 native 디렉터리를 추가하는 패치. 이미 native가 있으면 재적용하지 않는다.
- Synapse-0.1.0-SHA256.txt: DMG/소스/패치 체크섬.
- Synapse-local-test-guide.md: 설치·권한·검증 범위 안내.

0.1.0은 보내기·수정·삭제가 없는 읽기 전용 알파다. 원본 소스는 ../../native/에 있다.

2026-09-06 정리: 기존 안내서와 ZIP/DMG 내부 문서에는 생성 당시 프로젝트 쓰기가 차단되었다는 설명이 남아 있다. 이후 기존 승인된 파일 복사 경로로 이 프로젝트에 소스와 산출물 배치를 완료했다. 체크섬 보존을 위해 릴리스 바이너리와 소스 스냅샷은 변경하지 않았다.
