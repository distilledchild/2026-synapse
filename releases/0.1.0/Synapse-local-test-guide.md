# Synapse 0.1.0 — iMessage 로컬 테스트

Apple Silicon(M1 이상)용 읽기 전용 알파입니다. macOS 13 이상을 빌드 대상으로 설정했으며 실제 앱 실행 검증은 macOS 26.6.2에서 진행했습니다. 다른 OS 버전은 아직 실기기 검증하지 않았습니다.

## 설치와 연결

1. `Synapse-0.1.0-arm64.dmg`를 열고 **Synapse**를 **Applications(응용 프로그램)** 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 Synapse를 실행합니다. 처음에는 합성 샘플 대화만 표시됩니다.
3. **iMessage 연결**을 누릅니다.
4. 접근 안내가 나오면 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한에서 `Synapse.app`을 추가하고 켭니다.
5. 앱을 완전히 종료한 다음 다시 실행하고 **iMessage 연결**을 누릅니다.

메시지 앱에 이미 동기화된 대화를 읽습니다. SMS/RCS는 iPhone과 Apple 메시지 앱의 전달·동기화 설정에 따라 표시 여부가 다릅니다.

이 앱은 Apple Developer ID로 서명·공증되지 않은 개인 테스트 빌드입니다. macOS가 실행을 차단하면 시스템 설정의 개인정보 보호 및 보안에서 이 앱에 대한 ‘확인 없이 열기’가 제공되는지 확인하세요. 시스템 전체 보안 기능을 끄는 절차는 필요하지 않습니다. 전체 디스크 접근 권한은 사용자가 직접 설정해야 합니다.

## 이번 버전에서 확인할 기능

- 대화 목록과 메시지 열람, 한국어·이모지 표시
- 최근 최대 2,000개 일반 메시지 안에서 대화/본문 검색
- 연결 중 5초마다 새로고침, 수동 새로고침(Command-R)
- 불러온 범위 내 변경·삭제 반영
- 별도 macOS chat.db 파일 선택
- 연결 해제 시 읽어온 대화를 제거하고 샘플로 복귀

원본 DB는 읽기 전용으로 엽니다. 대화를 외부로 전송하거나 별도 캐시 파일로 저장하지 않으며 발신 기능이 없습니다. 사용자 메시지 DB에 대한 실제 접근은 아직 테스트하지 않았습니다.

## 알려진 범위

- 모든 과거 대화가 아니라 최근 2,000개 메시지를 대상으로 합니다. 시스템 이벤트와 리액션 행은 제외합니다.
- 표준 typedstream의 첫 NSString 본문을 해독합니다. 일부 특수 형식은 ‘본문을 표시할 수 없는 메시지’로 표시하며 미지원 건수를 보여줍니다.
- 첨부파일 다운로드/미리보기, 메시지 발신, 리액션 전송, 연락처 이름 변환은 미지원입니다.
- 원래 채팅의 편집·삭제 구조에 따라 변경이 완전히 반영되지 않을 수 있습니다. 현재 로드 범위의 원본 행을 다시 읽는 방식입니다.
- 앱 재실행 후에는 다시 연결해야 합니다. 전체 디스크 접근 권한을 철회하거나 빌드를 교체하면 재설정이 필요할 수 있습니다.

## 수행한 검증

- Swift 데이터 계층: 26개 검사와 잘린/임의 바이너리 입력 검사 통과.
- 일반/긴/한글/이모지 attributedBody, 최신 메시지 선택, 원본 DB 불변, WAL 신규 행, 편집·삭제, 미지원 형식 처리 검증.
- 실제 macOS 앱: 샘플 화면·한국어 검색·합성 DB 선택·자동 새로고침·연결 해제·도움말 확인.
- Apple Silicon 실행 파일, 자체 코드 서명 무결성, DMG 체크섬 확인.
- 미검증: 사용자 실제 메시지, 실제 전체 디스크 접근 권한 승인/철회, DMG 마운트 및 Applications로의 설치, 다른 macOS 버전. 현재 환경에서 가상 디스크 장치 연결이 제한되어 이미지는 파일 기반으로 생성·검증했습니다.
