# Synapse 0.2.7 — 사진 전송

입력창 옆 **+ → 사진 선택 → 미리보기 확인 → 사진 전송**으로 사진을 보낼 수 있습니다.

- [설치 DMG](Synapse-0.2.7-arm64.dmg)
- [사진 전송·설치 안내](Synapse-local-test-guide.md)
- [소스 ZIP](Synapse-0.2.7-source.zip)
- [SHA-256](Synapse-0.2.7-SHA256.txt)

JPG·PNG·HEIC·GIF·WebP 사진 한 장, 최대 20 MB를 지원합니다. 선택한 사진이 있으면 입력창의 Enter도 사진을 보냅니다. 작성 중인 글은 사진 전송 후 그대로 남으며 다음에 전송할 수 있습니다. 사진 옆 ×로 첨부를 취소할 수 있습니다.

파일 이동·변경·지원하지 않는 형식은 전송 전에 확인합니다. 실패하면 선택을 유지하며 결과 불명 상태에서 자동 재전송하지 않습니다. 별도 원본 복사본을 만들지 않으므로 메시지 앱에 사진이 나타날 때까지 선택한 파일을 유지하세요.

174개 검사와 합성 UI의 파일 선택·미리보기·사진 전송 후 글 보존을 확인했습니다. 실제 RCS 대화와 합성 사진 파일을 전송 없이 검사하는 production helper --check-target 결과는 ready입니다. 실제 사진 발신·배달은 수행하지 않았습니다. SMS/MMS·RCS 경로는 메시지 앱과 iPhone의 지원·연결 상태에 따릅니다.

Synapse를 종료하고 Applications의 앱을 교체한 뒤 다시 연결하세요. 개인 테스트용 ad-hoc 서명이며 Developer ID 서명·공증은 없습니다.
