# Synapse 0.2.6

중복 연락처의 이름이 숨겨지는 오류와 사진 위의 물음표 상자를 수정했습니다.

- [설치 DMG](Synapse-0.2.6-arm64.dmg)
- [설치·사용 안내](Synapse-local-test-guide.md)
- [소스 ZIP](Synapse-0.2.6-source.zip)
- [SHA-256](Synapse-0.2.6-SHA256.txt)

Mac 연락처 앱에서 제공된 두 번호에 각각 두 개의 저장 레코드가 있음을 확인했습니다. 검색 결과가 하나일 때만 이름을 표시하던 제한을 제거했습니다. 같은 이름은 합쳐서 한 번 표시하고, 서로 다른 저장 이름은 /로 구분합니다. 연락처 원본이나 전송 대상을 변경하지 않습니다.

사진 위의 네모 물음표는 실제 로컬 본문의 U+FFFE 내부 표시 문자였습니다. FFFC·FFFE·FFFF 첨부 표시 문자를 제거하고 사진만 있는 메시지는 목록에 첨부파일로 표시합니다. 일반 물음표와 실제 캡션·이모지는 유지합니다.

읽기 44개·전송 54개·연락처 31개·입력/이미지 21개(총 150개) 검사 통과. 실제 해당 메시지의 본문 정리와 첨부 유지, 앱 서명·DMG 무결성을 확인했습니다. 개인 테스트용 ad-hoc 서명이며 Developer ID 서명·공증은 없습니다.

Synapse를 종료하고 Applications의 앱을 교체한 뒤 다시 연결하세요. 이름 표시에는 연락처 접근 권한이 필요합니다.
