# Synapse 0.2.5

연락처 권한 연결, 링크 썸네일, 기본 한 줄 입력창을 수정했습니다.

- [설치 DMG](Synapse-0.2.5-arm64.dmg)
- [설치·권한 안내](Synapse-local-test-guide.md)
- [소스 ZIP](Synapse-0.2.5-source.zip)
- [SHA-256](Synapse-0.2.5-SHA256.txt)

기존 앱을 종료하고 Applications의 앱을 교체한 뒤 메시지를 연결하세요. 처음 나타나는 연락처 권한 창에서 **허용**을 선택하면 저장된 이름을 표시합니다. 거부했다면 왼쪽 아래 연락처 권한 설정에서 변경하세요.

링크의 내부 첨부 파일명 대신 저장된 대표 썸네일과 제목을 표시합니다. 제공된 Threads 링크의 실제 로컬 캐시에서 1024×939 이미지 디코딩에 성공했습니다. 별도 인터넷 다운로드는 없습니다.

입력창은 한 줄로 시작하고 내용에 따라 늘어나며 전송 후 줄어듭니다. Enter 전송·Shift+Enter 줄바꿈과 한글 조합 보호를 유지했습니다.

141개 검사, 합성 UI의 썸네일·한 줄/두 줄 입력·전송 후 복원, 앱 서명·DMG 무결성을 확인했습니다. 실제 연락처 권한 허용과 개인 계정 발신은 사용자 확인 대상입니다. 개인 테스트용 ad-hoc 서명이며 Developer ID 서명·공증은 없습니다.
