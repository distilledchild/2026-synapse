# Synapse 0.2.3

연락처 이름·이니셜 표시와 작성창 정리를 완료했습니다.

- [설치 DMG](Synapse-0.2.3-arm64.dmg)
- [설치·연락처 권한 안내](Synapse-local-test-guide.md)
- [소스 ZIP](Synapse-0.2.3-source.zip)
- [SHA-256](Synapse-0.2.3-SHA256.txt)

기존 Synapse를 종료하고 Applications의 앱을 교체한 뒤 메시지 연결 → 왼쪽 아래 **연락처 이름 표시**를 누르고 접근을 허용하세요. 이름이 확인된 대화는 같은 이름의 이니셜을 표시합니다. 미등록·중복 일치 번호는 번호와 사람 아이콘을 유지합니다.

작성창 위의 내부 ID·중복 문구를 제거하고 완료 상태를 짧게 표시합니다. 전송 대상 및 오류·결과 불명 처리는 유지했습니다.

읽기 29개·전송 54개·연락처 25개 검사(총 108개)와 합성 데이터 macOS 화면 검증을 통과했습니다. 앱·helper 서명, DMG 무결성과 소스 ZIP을 검증했습니다. 실제 연락처 권한 승인·사용자 연락처 일치와 실제 발신·배달은 설치 후 확인 대상입니다. 개인 테스트용 ad-hoc 서명이며 Developer ID 서명·공증은 없습니다.
