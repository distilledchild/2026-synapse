실행 중인 Synapse를 종료하고 Applications의 앱을 교체한 뒤 메시지를 연결하세요. Enter는 전송하고 Shift+Enter는 줄을 바꿉니다. 한글 입력기 조합 중 Enter는 전송하지 않습니다.

Mac에 내려받은 첨부 이미지를 말풍선 안에서 표시합니다. 클릭하면 크게 볼 수 있습니다. 이미지가 안 뜨면 메시지 앱에서 다운로드 상태와 접근 권한을 확인한 뒤 다시 불러오세요. GIF는 첫 프레임만 표시하며 50 MiB 초과 파일, 동영상 재생과 새 이미지 전송은 지원하지 않습니다.

읽기 35개·전송 54개·연락처 25개·입력/이미지 16개 검사(총 130개), 합성 데이터 macOS UI의 줄바꿈·전송·이미지 표시·확대 검증을 통과했습니다. 앱·helper 코드 서명, DMG 무결성과 ZIP을 확인했습니다. 실제 개인 계정 발신·첨부 파일 접근·연락처 권한 및 다른 macOS는 사용자 확인 대상입니다. 개인 테스트용 ad-hoc 서명이며 Developer ID 서명·공증은 없습니다.
