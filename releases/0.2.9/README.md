# Synapse 0.2.9 — History and English UI

Open a conversation to load its latest 1,000 messages, then use **Load older messages** to continue through the history stored on this Mac. Search keeps the full loaded conversation visible, highlights matching messages, and provides **Next match** navigation.

The interface, help, errors, permission prompts, accessibility labels, and sample conversations are in English. Real message text and contact names retain their original language. Names and unsaved numbers follow Apple Messages, with Contacts as a fallback. No custom naming feature is included.
